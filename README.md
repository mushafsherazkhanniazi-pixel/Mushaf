# 🛍️ LuxeStore — Premium E-Commerce Website

LuxeStore is a modern and responsive e-commerce website designed for selling premium technology, lifestyle, audio, gaming, and entertainment products.

The project is built using **HTML, CSS, and JavaScript** with a clean luxury-style user interface and a complete shopping flow.

## 💾 Cart Data

The shopping cart uses **localStorage**, allowing cart data to remain available when the user moves between pages or refreshes the website.

## 🔐 Security Note

This is a **frontend e-commerce project**. The checkout and payment options are presented as part of the user interface; a real production payment gateway, backend order processing system, database, authentication system and server-side security would need to be integrated separately.
